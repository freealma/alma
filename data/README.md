# Data Directory - Alma's Knowledge Base

This directory contains all of Alma's accumulated knowledge, experiences, and learnings organized into four main categories.

## Structure

```
data/
├── decisions/      # Architectural choices and reasoning
├── ideas/          # Creative concepts and future possibilities  
├── logs/           # Chronological progress and events
└── memories/       # Reflections and important learnings
```

## Purpose

- **Decisions**: Capture the "why" behind technical and architectural choices
- **Ideas**: Store creative sparks that may become future features
- **Logs**: Track daily progress, challenges, and milestones
- **Memories**: Preserve important lessons and reflections

## File Naming Convention

Use consistent naming: `YYYY-MM-DD-descriptive-title.md`

Example: `2025-04-06-project-structure-decisions.md`
